
# Data Science & Generative AI Submissions

## Description

This repository contains Jupyter Notebooks, data analysis exercises, and practical Python work completed as part of the **IB2AD0 Data Science & Generative AI** module at Warwick Business School, University of Warwick.

The repository documents my learning in data processing, feature engineering, and exploratory data analysis using Python, Pandas, NumPy, Matplotlib, and Seaborn.
